# Flowstate ⚡

A personal productivity hub built with React + Vite.

**Features:**
- Task manager with priorities, due dates & filters
- Pomodoro timer with custom durations & sound alerts
- Habit tracker with 7-day streak history
- Quick notes with word count
- Dark / light mode
- CSV export
- Fully persistent via localStorage

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This project is deployed on [Vercel](https://vercel.com). Push to `main` and Vercel auto-deploys.
